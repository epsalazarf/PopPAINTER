# PopCanvas: Popgen PCA Plotter (R Shiny)

_Current Major Version: v1.5 [September 2026]._

_Part of the [PopPAINTER](../README.md) suite._

This is the **stable, recommended** version of PopCanvas (`main` branch). A features preview (v2.0, Plotly-based) is under development on the `dev` branch — see [Which Version Should I Use?](../README.md#which-version-should-i-use) for details.

**Online version:** https://epsalazarf.shinyapps.io/PopCanvas/ · **Quick Start Guide:** [PopCanvas-guide.md](PopCanvas-guide.md)

## Description

**PopCanvas** is an interactive Shiny application for visualizing PCA results generated by population genomics software. The app reads `.eigenvec`/`.evec` (and optionally `.eigenval`/`.eval`) files from **PLINK 1.9**, **PLINK 2.0**, or **smartpca** (EIGENSOFT) — auto-detecting which one you're using — plus an optional `popinfo` file, to generate a customizable and interactive PCA plot. Users can zoom into specific regions of the plot, filter populations, and apply different labeling and coloring criteria.

### Requirements

- **R** (≥ 4.0); **RStudio** recommended.

- **R** packages:
  
  ```r
  install.packages(c("shiny", "dplyr", "readr", "ggplot2", "scales", "markdown"), dependencies = TRUE)
  ```

### Running the App

If you cloned the repo to your local machine, you can either: 

1. Open with RStudio open `PopCanvas-app.R` and click **Run App**, or from the R console:
   
   ```R
   shiny::runApp("PopPAINTER/PopCanvas/PopCanvas-app.R")
   ```

2. After the app starts, the side panel interface allows you to upload a `.eigenvec` file (optionally paired with its `.eigenval`) and a `popinfo.txt` file, or click **Load Demo Data** to try a built-in example. *Only the eigenvec file is required* — the eigenvalue file and POPINFO are both optional (see [Input Files](#input-files) below for what you lose without them).

3. Once the files are loaded and validated, the interactive PCA plot will be displayed.

## Features

- **Interactive Zoom**: Select and zoom into specific areas of the plot using the brush and double-click.
- **Population Selection**: Choose populations to display or highlight from the provided `popinfo` file.
- **Color Customization**: Use any category in the `popinfo` file to color the PCA points.
- **Dynamic Plot Options**: Choose between points, text, or population labels for plot markers.
- **Save Options**: Download the current plot as PNG or PDF.

### Input Files

- **Eigenvec file** *(required)*: `.eigenvec`/`.evec` output from PLINK 1.9, PLINK 2.0, or smartpca — see [File Formatting Guidelines](#file-formatting-guidelines) below for the differences between them. This alone is enough for a basic, uncolored PCA plot.
- **Eigenval file** *(optional)*: `.eigenval`/`.eval`, listing the eigenvalues. Without it, the plot still renders — the axis labels just drop the "(X% variance)" suffix.
- **Popinfo File** *(optional)*: A tab-separated `.txt/.tsv` file that includes information about population (`POP` column required) and other labels. The first column must match the sample IDs in the eigenvec file. Without it, there's no population to filter, emphasize, or color by — unless the eigenvec file carries a usable PLINK `FID` column (see below), coloring is unavailable too.

#### About the popinfo file

A `popinfo` is a metadata file links sample IDs to population and metadata categories along with other fields. PopCanvas relies on the `popinfo` for added functions like grouping, reordering and filtering. Make sure the `popinfo` file matches your data set and contains only relevant samples.

- **Required columns:**
  
  - `ID` — unique sample names.
  
  - `POP` — population code.

- **Recommended columns:**
  
  - `POPULATION` — human-readable population name.
  
  - `META` — grouping of populations for broader categories, typically linguistic, ethnic, or subcontinental groupings.
  
  - `SUPER` — grouping into very broad categories, typically continental-level.
  
  Recommended columns are optional, but when present PopCanvas expects them to follow a loose hierarchy: `ID` → `POP` → `META` → `SUPER`, from most to least granular.

- Example:
  
  ```
  ID       POP      POPULATION    META               SUPER
  HG00119  GBR      British       Northern European   EUR
  HG00120  GBR      British       Northern European   EUR
  HG00275  CHB      Han Chinese   East Asian          EAS
  ```

> **NOTE:** This app matches the sample IDs. If samples appear to be missing on the plot, check that the popinfo file contains the correct names in both files.

#### File Formatting Guidelines

- **Eigenvec File (`.eigenvec` / `.evec`)**: Must contain an ID column and the PCA values for each sample (PC1, PC2, etc.), with at least two components present, one sample per line. PopCanvas auto-detects which of these three output styles it's looking at, so you don't need to convert anything:

  - **PLINK 1.9** (`--pca`): space-delimited, with **no header row at all** — columns are always `FID IID PC1 PC2 ...` in that fixed order.
  - **PLINK 2.0** (`--pca`): tab-delimited, with a header row (e.g. `#IID` or `#FID IID`).
  - **smartpca** (EIGENSOFT) `.evec`: columns padded with variable-width whitespace rather than a single delimiter, and no real header row — just a leading `#eigvals:` line. A trailing case/control or population label column is dropped automatically (grouping should come from your own POPINFO file instead).

  If a PLINK `FID` column is present (PLINK 1.9 and 2.0 only — smartpca has none) and it isn't the default placeholder (`0`/`-9`), it becomes available as a "Group Coloring" option even without a POPINFO file, as long as it has between 2 and 20 unique values.

- **Eigenval File (`.eigenval` / `.eval`)**: Optional. A single-column file with one eigenvalue per line. PLINK lists one value per retained component; smartpca lists one for every possible component (as many as there are samples) — PopCanvas handles both correctly and uses the true total across all of them for the variance-explained percentage. Omitting this file just drops the "(X%)" suffix from the axis labels.

#### Example Data

Click the **Load Demo Data** button in the sidebar for a ready-to-go 1000 Genomes PCA plot — no files to find or upload.

Those files live in `PopCanvas/demo/`, in case you'd rather upload them yourself — e.g. to see how the upload flow works, or as a formatting reference:

- `demo.1kgp.eigenvec`

## Application Guide

### UI Controls

- **Title Input**: Set a custom title for the PCA plot.
- **Component Selection**: Choose principal components for X and Y axes.
- **Flip Axes**: Flip the X or Y axis if needed.
- **Plot Type**:
  - **Points**: Display points only.
  - **Text**: Show IDs as text labels.
  - **Labels**: Show population labels.
- **Populations Displayed**: Filter the displayed populations.
- **Population Emphasis**: Highlight a specific population.
- **Group Coloring**: Color the points by a chosen category (e.g., `POPULATION`, `REGION`).
- **Group Centroids**: Enable centroids for each population or group.
- **Legend**: Toggle legend display.

### Interactive Plotting

- **Zoom**: Select an area on the plot using the brush tool and double-click to zoom in.
- **Reset Zoom**: Double-click outside the selected area to reset the view.
- **Brush Info**: View metadata for the brushed points in the `Points Info` panel.

### Saving the Plot

- Click the sidepanel button **Save as PNG/PDF** to download the plot as a PNG/PDF file respectively. Note that rendering may change the exported file appearance.
- Alternatively, you can also right click the plot image in app to download it as a PNG. What you see is what you get.

### Data Table

- Click on the tab to visualize the merged PCA/metadata input table. Use the controls on the top to search, sort or filter through the sample table. Any filter applied in this tab has no effect on the plot.

## Troubleshooting

- Ensure that the `popinfo` file's first column matches exactly the IDs in the `.eigenvec` file.
- Check for missing or incorrectly formatted data in the input files.
- If the app fails to run, make sure all necessary R libraries are installed.
- If plots fail to render without an error message, restart your R/R Studio session.
